What you get

One API for the entire vol surface.

Query implied vol at any tenor, strike, moneyness or delta. Pull constant-maturity history. Get Greeks, forwards, and rates — all from one endpoint.

Vol surface, any strike

Single-point or bulk interpolated quotes. Specify strike, moneyness, or delta — the API solves for the right point and returns vol, price, and Greeks.

↬

Constant-maturity history

Daily time series at any fixed tenor and strike. Built for backtesting — one call returns the full date range. No more day-by-day loops.

σ

Realized vol + spot

Rolling realized vol (√365 annualized), daily spot prices per session, IV-RV gap analysis. Drop-in inputs for vol-risk-premium strategies.

3 sessions per day

Asia close (05:00 UTC), London close (12:00 UTC), US close (16:00 UTC). Same surface across sessions, so you can see how skew evolves intra-day.

Arbitrage-free fits

Calibrated with a no-arbitrage volatility model — multi-seed restart and degenerate-fit rejection. No butterfly violations. Same pipeline that drives the live dashboard.
